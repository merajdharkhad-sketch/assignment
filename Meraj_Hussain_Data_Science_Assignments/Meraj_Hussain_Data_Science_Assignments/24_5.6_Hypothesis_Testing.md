## Task 1: Test a new restaurant listing design
- **Null hypothesis (H0):** The new design does not increase the average number of daily orders.
- **Alternative hypothesis (H1):** The new design increases the average number of daily orders.
Compare order counts for users shown the old design and users shown the new design.

## Task 2: Interpret p-values at a 5% significance level
At significance level 0.05:
- If p-value < 0.05, reject H0; the result is statistically significant.
- If p-value >= 0.05, do not reject H0; there is not enough evidence to support H1.
A p-value is not the probability that H0 is true.

## Task 3: A/B test for a music recommendation algorithm
Randomly split users into two groups. Group A gets the current recommendation system; Group B gets the new system. Collect listening minutes per user over the same period.
- H0: The new algorithm does not increase average listening time.
- H1: The new algorithm increases average listening time.
Use a suitable statistical test and check that the groups were treated fairly.
