## Task 1: Declare four variables with different types
```python
daily_distance = 4.75
student_name = "Meraj Hussain"
spotify_subscribed = True
favorite_number = 7

print(daily_distance, type(daily_distance))
print(student_name, type(student_name))
print(spotify_subscribed, type(spotify_subscribed))
print(favorite_number, type(favorite_number))
```
The values show `float`, `str`, `bool`, and `int` types.

## Task 2: Convert price strings to floats and add them
```python
price_text = ["349.50", "120.00", "79.25"]
price_values = [float(item) for item in price_text]
grand_total = sum(price_values)
print("Total:", grand_total)
```

## Task 3: Check whether a phone number contains only digits
```python
def is_only_digits(phone_text):
    return phone_text.isdigit()

entered_phone = input("Enter phone number: ")
print(is_only_digits(entered_phone))
```
The phone number is kept as text because phone numbers may start with zero and are not used for arithmetic.
