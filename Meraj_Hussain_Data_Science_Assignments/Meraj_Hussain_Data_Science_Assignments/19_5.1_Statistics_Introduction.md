## Task 1: Eight variables in an app dataset
For a food delivery app, possible variables are:
1. `order_id` — unique order number
2. `customer_age` — customer's age
3. `restaurant_name` — restaurant name
4. `order_amount` — total bill
5. `delivery_minutes` — delivery duration
6. `restaurant_rating` — rating given by a user
7. `payment_method` — cash, card, or UPI
8. `items_count` — number of items in an order

## Task 2: Variable type examples
| Variable | Example | Type |

| Customer feedback | 1 to 5 stars | Ordinal |

## Task 3: Two cricket features
- **Runs scored:** numerical; can be summarized with mean, median, and range.
- **Batting style:** categorical; can be counted to compare right-handed and left-handed batters.
