## Task 1: Store order details and explain them
```python
customer_name = "Meraj"
last_order_amount = 425.50
coupon_used = True

# These variables store a name, order amount, and coupon status.
print(customer_name)
print(last_order_amount)
print(coupon_used)
```
`customer_name` stores text, `last_order_amount` stores a number with decimals, and `coupon_used` stores a True/False value.

## Task 3: Demonstrate dynamic typing
```python
playlistCount = 12
print(playlistCount)

playlistCount = "Evening Mix"
print(playlistCount)
```
Python lets a variable refer to values of different types at different times. Clear variable names are still recommended.
