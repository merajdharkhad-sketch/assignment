## Task 1: Variance of daily steps
```python
def variance(values):
    if len(values) <= 1:
        return 0
    average = sum(values) / len(values)
    return sum((value - average) ** 2 for value in values) / len(values)

steps = [5000, 5200, 4900, 5300, 5100]
print("Variance:", variance(steps))
```
This uses population variance, dividing by the number of values.

## Task 2: Standard deviation of monthly mobile data
```python
import math

def std(values):
    if len(values) <= 1:
        return 0
    avg = sum(values) / len(values)
    var = sum((value - avg) ** 2 for value in values) / len(values)
    return math.sqrt(var)

monthly_gb = [18, 20, 19, 21, 18, 20]
spread = std(monthly_gb)
print("Standard deviation:", round(spread, 2))
if spread < 3:
    print("Usage is consistent")
else:
    print("Usage is varied")
```
The threshold of 3 GB is chosen for this example.

## Task 3: Compare two tests
```python
coding_marks = [72, 75, 70, 78, 74]
music_marks = [40, 92, 65, 98, 55]
print("Coding variance:", variance(coding_marks))
print("Music quiz variance:", variance(music_marks))
# The test with the larger variance has more variation in marks.
```

## Task 4: Empty or one-value input
The `variance()` and `std()` functions above return `0` when the list has zero or one item, so they safely handle these cases without using NumPy or another statistics library.
