## Task 1: Total ten order prices
```python
order_prices = [180, 450, 220, 799, 120, 340, 265, 510, 199, 620]
total_spent = 0
for amount in order_prices:
    total_spent += amount
print("Total spent:", total_spent)
```

## Task 2: Delivery countdown
```python
minutes_left = 10
while minutes_left >= 0:
    print(minutes_left, "minutes remaining")
    minutes_left -= 1
```

## Task 3: Stop at the first post with more than 1,000 likes
```python
post_likes = [240, 510, 870, 1340, 600, 1800]
checked_posts = 0
for likes in post_likes:
    checked_posts += 1
    if likes > 1000:
        break
print("Posts checked:", checked_posts)
```

## Task 4: Print playlist positions using enumerate
```python
playlist_names = [
    "Chill Vibes", "Workout Hits", "Road Trip", "Old Classics",
    "Study Beats", "Indie Evening", "Rainy Day", "Party Mix"
]
for position, title in enumerate(playlist_names, start=1):
    print(f"{position}. {title}")
```
