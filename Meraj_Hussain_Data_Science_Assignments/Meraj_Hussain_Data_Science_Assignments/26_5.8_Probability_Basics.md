## Task 1: Simple probability function
```python
def calcul_probability(total_outcomes, favorable_outcomes):
    if total_outcomes <= 0 or favorable_outcomes < 0 or favorable_outcomes > total_outcomes:
        raise ValueError("Check the number of outcomes")
    return favorable_outcomes / total_outcomes

# Example: 3 blue balls out of 10 balls
print("Probability:", calcul_probability(10, 3))
```

## Task 3: Probability of an Ace and a red card
A standard deck has 52 cards and 4 Aces.
- P(Ace) = 4/52 = 1/13, about 7.69%.
- There are 26 red cards, so P(red card) = 26/52 = 1/2 = 50%.

## Task 4: Conditional probability of a red face card
There are 6 red face cards (Jack, Queen, King of hearts and diamonds) in a 52-card deck.
- P(red face card) = 6/52 = 3/26, about 11.54%.
If the card is already known to be red, then P(face card | red) = 6/26 = 3/13, about 23.08%.

## Task 5: Probability a pizza order was placed at night
Night orders: 60%; 30% of night orders are pizza. Day orders: 40%; 10% of day orders are pizza.
P(night | pizza) = P(pizza | night)P(night) / P(pizza)
= (0.30 × 0.60) / ((0.30 × 0.60) + (0.10 × 0.40))
= 0.18 / 0.22 = 0.8182.
So about **81.82%** of pizza orders were placed at night.
