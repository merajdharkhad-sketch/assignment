## Short note
Skewness describes whether a distribution is balanced or has a longer tail on one side.
- **Near zero:** data is roughly balanced.
- **Positive skew:** a few large values stretch the right tail, such as delivery bills with a few very expensive orders.
- **Negative skew:** a few small values stretch the left tail.

## Python example
```python
def mean(values):
    return sum(values) / len(values) if values else 0

def median(values):
    if not values:
        return None
    ordered = sorted(values)
    middle = len(ordered) // 2
    if len(ordered) % 2:
        return ordered[middle]
    return (ordered[middle - 1] + ordered[middle]) / 2

bills = [180, 200, 220, 230, 250, 1200]
print("Mean:", mean(bills))
print("Median:", median(bills))
```
