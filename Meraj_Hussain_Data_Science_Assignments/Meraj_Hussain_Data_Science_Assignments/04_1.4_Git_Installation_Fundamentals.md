## Task 1: Install and verify Git
Install Git from https://git-scm.com/downloads. Open a new terminal and run:
```bash
git --version
```
A version number confirms that Git is available.

## Task 2: Set your identity
```bash
git config --global user.name "Meraj Hussain"
git config --global user.email "YOUR-EMAIL@example.com"
git config --global --list
```
Replace the sample email with the email you use for GitHub.

## Task 3: Create a Recipe Collection repository
```bash
mkdir RecipeCollection
cd RecipeCollection
git init
echo "# Recipe Collection" > README.md
echo "Masala poha: poha, onion, mustard seeds and lemon." > recipe.txt
git add .
git commit -m "Add first recipe"
```

## Task 4: Clone a public repository
```bash
git clone https://github.com/pandas-dev/pandas.git
```
This downloads a copy of the public Pandas repository. You can use another public repository if preferred.

## Task 5: Add wishlist.txt and push it
Create a new empty GitHub repository called `RecipeWishlist`, then run:
```bash
mkdir RecipeWishlist
cd RecipeWishlist
git init
echo "Things to learn: Python, pandas, and charts." > wishlist.txt
git add wishlist.txt
git commit -m "Add learning wishlist"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/RecipeWishlist.git
git push -u origin main
```
