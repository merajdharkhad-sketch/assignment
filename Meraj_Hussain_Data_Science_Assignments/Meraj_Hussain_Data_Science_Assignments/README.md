# Meraj Hussain — Data Science Assignments

This folder contains one Markdown file per assignment topic. Each file has the task answers in simple language and Python examples where relevant.

## How to use
- Open the `.md` files in VS Code, Notepad, Typora, or any Markdown editor.
- Python code blocks can be copied into a `.py` file or Jupyter Notebook.
- For plots, install the required packages with `pip install matplotlib numpy`.
- For the data-cleaning example, install pandas with `pip install pandas`.
- Replace `YOUR-USERNAME` and placeholder emails in Git commands before running them.
