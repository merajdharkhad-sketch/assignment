## Task 1: Create a GitHub account
1. Open https://github.com and sign up.
2. Verify the email address.
3. Choose a username and complete the profile.
4. Use the account to store project repositories.

## Task 2: Make the first commit for an InstaClone demo
Run these commands in a terminal:
```bash
mkdir InstaCloneDemos
cd InstaCloneDemos
git init
echo "# InstaClone Demo" > README.md
git add README.md
git commit -m "Initial commit for InstaCloneDemos"
```

## Task 3: Create PlaylistTracker and push top five songs
First create a **public** repository named `PlaylistTracker` on GitHub without adding a README. Then run:
```bash
mkdir PlaylistTracker
cd PlaylistTracker
git init
echo "My Top Five Spotify Songs" > songs.txt
echo "1. Song One" >> songs.txt
echo "2. Song Two" >> songs.txt
echo "3. Song Three" >> songs.txt
echo "4. Song Four" >> songs.txt
echo "5. Song Five" >> songs.txt
git add .
git commit -m "Add my top five songs"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/PlaylistTracker.git
git push -u origin main
```
Replace `YOUR-USERNAME` with your GitHub username and replace the sample song names with songs you actually choose.
