## Task 1: Change a product name to title case and replace hyphens
```python
product_name = "wireless-earbuds-pro"
clean_name = product_name.replace("-", " ").title()
print(clean_name)
```

## Task 2: Split a product description into features
```python
description = "long battery life, fast charging, noise reduction, compact case"
features = description.split(", ")
for feature in features:
    print(feature)
```

## Task 3: Get the brand name from the beginning of a product name
```python
def get_brand(full_product_name):
    parts = full_product_name.split()
    return parts[0]

print(get_brand("Realme Narzo Phone"))
```
This solution assumes the brand is the first word.
