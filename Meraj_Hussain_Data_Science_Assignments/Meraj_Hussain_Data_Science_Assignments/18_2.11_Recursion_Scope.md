## Task 1: Recursively add the play counts of the first n songs
```python
def sum_plays(play_counts, n):
    if n <= 0:
        return 0
    return play_counts[n - 1] + sum_plays(play_counts, n - 1)

song_plays = [120, 95, 210, 160, 80]
print(sum_plays(song_plays, 4))
```

## Task 2: Show local and global variables
```python
discount = 5  # Global variable

def apply_coupon():
    discount = 10  # Local variable; this does not change the global variable
    print("Inside function:", discount)

apply_coupon()
print("Outside function:", discount)
```
The local variable exists inside the function. The global variable remains 5.

## Task 4: Recursive factorial and call stack
```python
def factorial(number):
    print("Calling factorial with:", number)
    if number <= 1:
        return 1
    result = number * factorial(number - 1)
    print("Returning from:", number)
    return result

print("Factorial:", factorial(4))
```
For `factorial(4)`, Python calls 4, then 3, then 2, then 1. Once the base case returns 1, the waiting calls return 2, 6, and 24. Each call stays on the call stack until its result is ready.
