## Task 2: Create a matrix with Python lists
Each row represents a post and each column represents likes, comments, and shares.
```python
engagement_matrix = [
    [120, 14, 8],
    [85, 9, 4],
    [160, 22, 12],
    [95, 11, 5]
]
print("Matrix:")
for row in engagement_matrix:
    print(row)
```

## Task 3: Access a matrix item by index
```python
print("Likes for third post:", engagement_matrix[2][0])
```
Python uses zero-based indexing, so row index 2 means the third row.

## Task 4: Add two vectors
```python
likes_week_one = [10, 20, 30]
likes_week_two = [5, 12, 8]
combined_likes = [a + b for a, b in zip(likes_week_one, likes_week_two)]
print(combined_likes)
```
