## Task 1: Create a repository and push it
Create an empty GitHub repository, then:
```bash
mkdir PlaylistRating
cd PlaylistRating
git init
echo "const rating = 4;" > rating.js
git add .
git commit -m "Add starting rating file"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/PlaylistRating.git
git push -u origin main
```

## Task 2: Create and push a feature branch
```bash
git switch -c feature/add-rating
echo "function showRating() { return rating; }" >> rating.js
git add rating.js
git commit -m "Add rating helper"
git push -u origin feature/add-rating
```

## Task 3: Simulate and resolve a merge conflict
On `main`, edit the same line in `rating.js` to `const rating = 5;`, then commit it:
```bash
git switch main
git add rating.js
git commit -m "Update default rating"
git switch feature/add-rating
git merge main
```
If Git reports a conflict, open `rating.js`, remove the conflict markers (`<<<<<<<`, `=======`, `>>>>>>>`), and keep the correct combined code. Then:
```bash
git add rating.js
git commit -m "Resolve rating merge conflict"
```
A conflict happens when two branches change the same part of a file differently.

## Task 4: Open a Pull Request
Push the feature branch and open GitHub. Select **Compare & pull request**, describe the change, and submit the Pull Request for review. Merge it after review.
