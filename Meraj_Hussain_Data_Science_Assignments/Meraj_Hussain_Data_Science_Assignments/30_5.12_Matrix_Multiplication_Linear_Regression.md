## Task 1: Calculate slope and intercept with basic Python
Suppose `x` is daily step count measured in thousands and `y` is estimated calories burned. The simple linear model is `y = m*x + c`.
```python
def fit_line(x_values, y_values):
    if len(x_values) != len(y_values) or len(x_values) < 2:
        raise ValueError("Provide equally sized lists with at least two points")
    x_mean = sum(x_values) / len(x_values)
    y_mean = sum(y_values) / len(y_values)
    covariance = sum((x - x_mean) * (y - y_mean)
                     for x, y in zip(x_values, y_values)) / len(x_values)
    variance_x = sum((x - x_mean) ** 2 for x in x_values) / len(x_values)
    if variance_x == 0:
        raise ValueError("x values must not all be the same")
    slope = covariance / variance_x
    intercept = y_mean - slope * x_mean
    return slope, intercept

steps_thousands = [2, 4, 6, 8, 10]
calories = [70, 130, 190, 250, 310]
m, c = fit_line(steps_thousands, calories)
print("Slope:", m, "Intercept:", c)
```

## Task 2: Predict calories from steps
```python
def predict_calories(steps):
    steps_in_thousands = steps / 1000
    return m * steps_in_thousands + c

print("Estimated calories for 7,000 steps:", predict_calories(7000))
```
This is only a simple practice model. Real calorie burn depends on more than step count.

## Short explanation
Linear regression finds a line that represents the relationship between an input and an output. The slope tells how much the prediction changes when the input increases by one unit, and the intercept is the predicted output when the input is zero.
