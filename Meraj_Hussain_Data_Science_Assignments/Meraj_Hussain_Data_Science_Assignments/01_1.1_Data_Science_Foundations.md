## Task 3: Three main pillars
1. **Statistics:** Helps us understand data using averages, percentages, and patterns. Example: finding the average delivery time.
2. **Programming:** Helps us clean data and perform calculations quickly. Example: using Python to count orders.
3. **Domain knowledge:** Means understanding the subject we are studying. Example: a cricket analyst needs to understand runs, wickets, overs, and match conditions.

All three are useful together: domain knowledge defines the right question, statistics helps interpret the data, and programming processes it.
