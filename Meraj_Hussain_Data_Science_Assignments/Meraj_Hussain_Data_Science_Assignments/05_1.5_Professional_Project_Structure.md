## Task 1: Create a project folder
A suitable `spotify-data-analysis` structure is:
```text
spotify-data-analysis/
├── data/
│   ├── raw/
│   └── processed/
├── notebooks/
├── src/
├── reports/
├── README.md
├── requirements.txt
└── .gitignore
```
Raw data stays unchanged; cleaned data goes in `processed`; notebooks contain experiments; `src` contains reusable code; and `reports` stores results.

## Task 2: Create a .gitignore
```gitignore
__pycache__/
.ipynb_checkpoints/
.env
.venv/
venv/
data/raw/
*.csv
.DS_Store
```
This example ignores raw data and CSV files. If a small sample CSV is required for the project, use a more specific rule such as `data/raw/*.csv` and add an exception for the sample file.

## Task 3: Write README.md
```markdown
# Spotify Data Analysis

## Goal
Explore listening patterns and identify popular tracks and artists.

## Project folders
- data: raw and processed datasets
- notebooks: analysis notebooks
- src: reusable Python code
- reports: charts and findings

## Tools
Python, pandas, Matplotlib

## How to run
Install packages with `pip install -r requirements.txt`, then open the notebook in `notebooks/`.
```

## Task 4: Initialize Git
```bash
cd spotify-data-analysis
git init
git add README.md .gitignore
git commit -m "Set up Spotify analysis project"
```

## Task 5: Compare with a machine-learning project
A machine-learning project would usually add folders such as `models/`, `features/`, and `tests/`, plus training and evaluation scripts. A data-analysis project mainly focuses on exploration, summaries, and charts.
