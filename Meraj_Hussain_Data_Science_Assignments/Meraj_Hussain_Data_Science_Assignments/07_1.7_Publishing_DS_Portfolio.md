# 1.7 Publishing Projects and Building a Data Science Portfolio
**Student:** Meraj Hussain | **Course:** Data Science

## Task 1: Publish a data-science project
Choose a small project such as IPL score analysis or restaurant rating analysis. Include a README, sample data that you are allowed to share, code, and a few useful charts.

## Task 2: Add an IPL CSV file
Save a permitted IPL dataset as `ipl_matches.csv` inside the repository. Then:
```bash
git add ipl_matches.csv
git commit -m "Add IPL match dataset"
git push
```
Do not upload private or copyrighted data unless you have permission.

## Task 3: Show code changes with Git
Edit a notebook or script, then run:
```bash
git diff
git status
git add .
git commit -m "Improve analysis chart"
git push
```
`git diff` shows edits that have not yet been committed.

## Task 4: Create a portfolio with GitHub Pages
Create a repository named `YOUR-USERNAME.github.io`. Add an `index.html` file:
```html
<!doctype html>
<html lang="en">
<head><meta charset="utf-8"><title>Meraj Hussain | Data Science</title></head>
<body>
  <h1>Meraj Hussain</h1>
  <p>I am learning data science, Python, and data visualization.</p>
  <h2>Projects</h2>
  <p><a href="https://github.com/YOUR-USERNAME">View my GitHub projects</a></p>
</body>
</html>
```
Replace the placeholder username. Enable GitHub Pages in repository settings.

## Task 5: Share a report
Add a PDF report or notebook to your project and link it from the README. A button or image preview can make it easier to find.
