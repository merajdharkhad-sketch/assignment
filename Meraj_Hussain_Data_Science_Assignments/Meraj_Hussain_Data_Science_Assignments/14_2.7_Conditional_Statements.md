## Task 1: Check whether music has played for an hour
```python
listening_minutes = 68

```

## Task 2: Check free delivery eligibility
```python
cart_total = 560
if cart_total >= 500:
    print("Eligible for free delivery")
else:
    print("Delivery charges apply")
```

## Task 3: Give a discount based on cart value
```python
cart_value = 1450
if cart_value > 2000:
    print("You get a 15% discount")
elif cart_value >= 1000:
    print("You get a 10% discount")
elif cart_value >= 500:
    print("You get a 5% discount")
else:
    print("No discount")
```
