## Task 1: Problem statement for an app
**App:** Zomato  
**Business problem:** Users may leave the app if delivery estimates are inaccurate.  
**Goal:** Predict delivery time more accurately using distance, traffic, restaurant preparation time, weather, and past delivery records. Success can be measured by comparing predicted time with actual delivery time.

## Task 2: Three types of data and possible sources
1. **Order details** (items, order time, restaurant): database or official API.
2. **Delivery details** (distance, delivery duration): company database or API.
3. **Customer feedback** (rating and review): database or permitted API.  
Data should only be collected with permission and according to privacy rules.

## Task 3: Clean a sample food-order dataset
```python
import pandas as pd

orders = pd.DataFrame({
    "restaurant": ["Spice Corner", None, "Green Bowl", "City Biryani"],
    "amount": [280, 190, 350, 220],
    "minutes": [32, 25, None, 40]
})

clean_orders = orders.dropna().copy()
clean_orders["restaurant"] = clean_orders["restaurant"].str.lower()
print(clean_orders)
```
This removes rows with any missing value and converts restaurant names to lowercase.

## Task 4: Explore the cleaned data
```python
print("Rows and columns:", clean_orders.shape)
print("Column types:")
print(clean_orders.dtypes)
print("Summary:")
print(clean_orders.describe(include="all"))
print("Restaurants:", clean_orders["restaurant"].tolist())
```
The summary shows the number of records, column types, and basic statistics.
