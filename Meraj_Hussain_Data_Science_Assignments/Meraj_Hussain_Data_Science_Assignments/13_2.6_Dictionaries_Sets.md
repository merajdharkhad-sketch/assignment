## Task 4: Find food items ordered in both weeks and all unique items
```python
last_week = {"Dosa", "Pizza", "Pav Bhaji", "Sandwich"}
this_week = {"Pizza", "Sandwich", "Biryani", "Khichdi"}
print("Both weeks:", last_week.intersection(this_week))
print("All items:", last_week.union(this_week))
```

## Task 5: Find Instagram accounts with over 10,000 followers
```python
insta_followers = {
    "food_diary_amit": 8400,
    "travel_with_riya": 15600,
    "code_by_neel": 22400,
    "daily_sketches": 7200

    if followers > 10000:
```
