## Task 2: Calculate correlation using basic Python
```python
import math

def compute_correlation(x, y):
    if len(x) != len(y) or len(x) < 2:
        raise ValueError("Lists must have equal length and at least two values")
    mean_x = sum(x) / len(x)
    mean_y = sum(y) / len(y)
    numerator = sum((a - mean_x) * (b - mean_y) for a, b in zip(x, y))
    denominator_x = math.sqrt(sum((a - mean_x) ** 2 for a in x))
    denominator_y = math.sqrt(sum((b - mean_y) ** 2 for b in y))
    if denominator_x == 0 or denominator_y == 0:
        return None
    return numerator / (denominator_x * denominator_y)

print(compute_correlation(watch_minutes, post_likes))
```

## Task 3: Example movie data
```python
movie_hours = [1.5, 2.0, 1.8, 2.2, 1.6, 2.4, 2.1, 1.7, 2.3, 1.9]
movie_ratings = [3.1, 4.0, 3.6, 4.2, 3.3, 4.6, 4.1, 3.4, 4.5, 3.8]
result = compute_correlation(movie_hours, movie_ratings)
print("Correlation:", result)
if result is not None and result > 0:
    print("Positive correlation")
elif result is not None and result < 0:
    print("Negative correlation")
else:
    print("Zero or undefined correlation")
```
The sample suggests a positive relationship between runtime and rating, but a small sample cannot prove a general rule.

## Task 4: Explain why correlation is not causation
A strong relationship between food videos watched and food orders does not prove that watching videos causes orders. Hunger, time of day, advertising, or income may affect both. More data or a controlled experiment would be needed.
